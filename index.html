Domain Engineering & Privacy-First Repositories

Stand-alone, client-side tools built to eliminate institutional spreadsheet drag.

LedgerDuck

Zero-Knowledge SQL Audit Engine
100% In-Browser

Core Problem Solved: Auditing large general ledgers and trial balances without leaking confidential records to cloud servers or crashing Excel.

Architecture & Privacy Design: Powered by DuckDB-Wasm and React; runs 100% in-browser. Features ingestion guardrails (merged cell rejection, rectangular validation), 1-click audit checks (split payments, round sums, materiality outliers), and a schema-only LLM prompt helper.
DuckDB-Wasm React Client-Side SQL
Repository

Corporate Structure Builder

Local-First Infinite Canvas
Dexie.js DB

Core Problem Solved: Managing multi-tier corporate hierarchies, dynamic cap tables, and UBO allocations in static spreadsheets creates visualization blind spots.

Architecture & Privacy Design: Built with Vue 3, Pinia, Vue Flow, and Dagre graph layout. Uses Dexie.js (IndexedDB) for 100% local persistence. Features temporal historical travel, live cap table balancing, and clean unbranded compliance PDF/SVG export.
Vue 3 Vue Flow IndexedDB
Repository

Accounting Narration Generator

Daily Rollover & Journal Generator
Live Online

Core Problem Solved: Repetitive manual calculation and typing required for daily rollover deposit journal entries under fluctuating floating interest rates.

Architecture & Privacy Design: Built with Vue 3 & LocalStorage. Automates working-day schedules (excluding banking holidays), daily interest calculations, chained closing balances, and template-based entry generation. Zero data transmission.

SheetJS Engine
